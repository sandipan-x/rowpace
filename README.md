# RowPace

Rowing pace calculator: convert split, watts, time and distance with the Concept2 formula. Zone gauge, Paul's Law predictions, 2K benchmarks. Free.

## Features
- Zone needle gauge: watts mapped to Easy/Steady/Threshold/Race effort zones
- Two-way converter: any of distance, time, split or watts derives the rest
- Paul's Law predictor for 1K/5K/10K/60min plus 2K benchmark table
